# hellwaytim portfolio

React + TypeScript + Vite project for a warm editorial portfolio website with fictional case pages.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/App.tsx` — hash-based routing between home and case pages
- `src/data.ts` — colors, services, case studies, pricing
- `src/components/*` — reusable UI and page sections
- `src/styles.css` — responsive global styles

Author label used throughout: **hellwaytim**.
